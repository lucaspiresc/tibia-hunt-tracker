# Catálogo

`tracker_catalog.json` contém somente entradas ativas com duração fixa recomendadas para o tracker.

O catálogo foi gerado em 21 de setembro de 2026 a partir do TibiaWikiApi, cujo upstream é o TibiaWiki/Fandom, e comparado com as tabelas relevantes do TibiaWiki BR. O conteúdo derivado do wiki mantém atribuição e deve obedecer à licença indicada pelo projeto (CC BY-SA).
